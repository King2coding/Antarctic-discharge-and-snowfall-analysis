# Data guide

Research data are intentionally excluded from this public code archive. The
original rain-server working directory remains the authoritative location for
authorized local data and generated products.

The workflows reference several broad data categories:

- Antarctic drainage-basin boundaries and masks;
- gridded monthly precipitation and snowfall products;
- ice-sheet discharge time series;
- GRACE and GRACE-FO mass-change observations;
- regional climate-model surface-mass-balance products;
- passive-microwave sensor records, including SSMIS F17 diagnostics; and
- intermediate correction-factor tables, evaluation statistics, and figures.

Two generated monthly mass-budget NetCDF files that were present in the original
Git history were removed from the public repository history. They remain in the
original working environment and are not required to understand the source-code
organization.

To run a workflow, inspect its path/configuration section and provide equivalent
authorized datasets locally. Do not commit data, credentials, unpublished
manuscripts, reviewer material, or generated outputs to this repository.
